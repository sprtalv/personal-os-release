# Connect a host

Point the assistant at this Skill and a separate private data directory. Enable only the history, scheduling, and connector access the person chooses. The repository does not install these capabilities.

- **On a user message:** Answer first. Record meaningful new facts, decisions, corrections, and outcomes only within the chosen scope. Use the original source reference, then report the save or failure.
- **Morning:** Check actual calendar and task state when available. Make a short editable plan. A draft creates no events; wait for the user's confirmation where required.
- **Evening:** Read only new relevant messages, reconcile outcomes and due questions, then invite a short optional review. Record a send only after the host acknowledges it; reconcile replies separately.
- **Weekly / monthly:** Reuse the same evidence, review actual results and changed assumptions, and pick the next steps. Include training, nutrition or skin observations only when relevant.
- **Deployment:** Configure schedules, messaging, calendar/tasks, and private Git in the host separately. Verify one sandbox run, one real delivery if enabled, and a backup restore. Keep credentials and runtime receipts outside this repository.
