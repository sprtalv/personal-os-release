# 设计依据与证据边界

这些资料用于解释产品选择，不是 Personal OS 已改善生活、学习、健康或长期决策的证据。每项映射都需要在实际用户场景中验证采纳、负担、结果和副作用；本技能不作临床诊断或治疗承诺。

| 来源与性质 | 在本技能中的谨慎映射 | 边界 |
|---|---|---|
| [FranklinCovey：Begin With the End in Mind](https://www.franklincovey.com/courses/the-7-habits/habit-2/)；实践框架 | 重要项目先记录为什么做、成功标准与取舍 | 不是此软件的效果试验，也不要求人人写使命宣言 |
| [James Clear：Atomic Habits](https://jamesclear.com/atomic-habits)；书籍原则 | 启动困难时提供一个小而可见的下一步 | 书籍原则不等于本产品或某个人的效果证据 |
| [Gollwitzer 与 Sheeran 2006：实施意向综述](https://www.socmot.uni-konstanz.de/publications/implementation-intentions-and-goal-achievement-meta-analysis-effects-and-processes)；元分析 | 可选的“情境→动作”提示 | 不能保证每个用户、目标和情境都有效；不强制作出计划 |
| [Harkin 等 2016：目标进展监测元分析](https://pubmed.ncbi.nlm.nih.gov/26479070/)；元分析 | 在有意义的目标上轻量检查预期与结果 | 记录频率和用户负担须另行验证；不为每句聊天打分 |
| [Lally 等 2010：习惯形成研究](https://onlinelibrary.wiley.com/doi/10.1002/ejsp.674)；特定样本的观察研究 | 中断后允许最小重启，不按单次失约惩罚 | 个体形成速度差异大；不推导固定天数或人格 |
| [Deci 与 Ryan 2000：自我决定理论](https://selfdeterminationtheory.org/SDT/documents/2000_DeciRyan_PIWhatWhy.pdf)；理论综述 | 保留自主选择、可暂停及用户自己定义的目标 | 理论不是此产品长期增益的验收结果 |
| [Eikey 2021：个人信息工具与反刍](https://link.springer.com/article/10.1007/s00779-021-01573-w)；人机交互研究 | 避免惩罚式连续打卡和过密自我量化，允许跳过 | 不能把任何记录方式直接诊断为有害或有效 |
| [LongMemEval](https://xiaowu0162.github.io/long-mem-eval/)；长记忆基准 | 对来源、时间、更新与不确定回答做可检查的记忆评估 | 基准分数不等于真实个人理解或长期建议质量 |
| [Bansal 等 2021：AI 解释与协作表现](https://www.microsoft.com/en-us/research/publication/does-the-whole-exceed-its-parts-the-effect-of-ai-explanations-on-complementary-team-performance/)；人机协作研究 | AI 建议要能被用户拒绝，并分开记录采纳与实际结果 | 解释可能增加接受建议的机会，却不保证建议正确 |

目前代码能强制部分结构关系、失效引用检查和幂等写入；它不能从原文自动判定人的真实动机、因果、副作用或建议的长期价值。应把这些判断与缺口明确呈现给用户，再用自然反馈修订，而非生成单一“生活分数”。
