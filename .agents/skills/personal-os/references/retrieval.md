# 历史检索

## 确定范围

从当前问题确定对象、时期和意图：查事实、比较变化、解释结果、寻找经验或获取当前安排。利用已有上下文解析“那个方案”等指代；存在多个合理对象时询问，不默选。

查询当前状态优先读 `data/current/` 及其依据；查询过去的观点使用对应时间的历史记录。涉及待办和日程时读取授权工具最新状态，记录中的快照只作为历史背景。

## 查找与扩展

1. 查询项目、人物、主题、实际名称及已知别名，使用日期范围缩小候选。
2. 使用脚本索引与全文检索查候选记录；改用相关概念、近义表达或明确名称补查。索引过时则重建或直接搜索原文件。
3. 阅读候选记录的正文、来源、时间、依据类型与状态。不要根据摘要或搜索片段直接下结论。
4. 沿关联读取原决定、当时假设、后续结果、纠错与观点变化。优先检查候选结论的相反证据。
5. 需要解释过程时读取案例，并返回基础记录核对。报告中的分析不能取代原始依据。

从 Skill 目录执行：

```bash
python scripts/records.py index --root ROOT
python scripts/records.py search --root ROOT --query '项目名称'
python scripts/records.py search --root ROOT --query '当时的观点' --include-history
```

`--include-history` 用于查找已被替代或纠错的历史；必须检查状态，旧错误不能作为当前事实。全文搜索不保证语义召回，找不到时扩大词语与时间范围，并沿已有实体或案例关联补查。

## 按问题选择证据

| 问题 | 必要材料 |
|---|---|
| 上次为什么放弃方案 | 当时目标、约束、比较过的选择、本人理由、后续补充 |
| 为什么决策失败 | 决策前信息、原预期、执行、外部变化、实际结果、替代解释 |
| 最近状态为何好 | 本人描述、时间段、同期条件、相似时期、反例 |
| 当前与过去目标有何变化 | 两个时期的有效观点、变化记录和原因 |
| 之前事项有什么结果 | 原问题、最近进展、工具观察、结果记录与跟进状态 |

## 输出与缺口

回答时按问题给出结论、关键依据和适当的不确定性；需要时展示记录引用。分清“用户当时说过”“工具显示”“AI 认为可能”。

没有找到只能说“目前没有找到相关记录”，不能说“从未发生”。时间覆盖不足、来源不可访问或条件不可比时明确限制。只在缺口影响当前判断时补问，不为填满档案要求用户回忆所有细节。

检索命中不代表对象一定相同。重复导入使用来源身份、事件时间和具体对象校验；不同日期的相似经历应作为独立证据关联。
